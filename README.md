# E-Commerce Retention Analytics: RFM Segmentation & Churn Prediction

## Project Overview

This project analyzes e-commerce customer behavior using RFM (Recency, Frequency, and Monetary) analysis, customer segmentation, and churn prediction.

The goal is to identify valuable customer segments, understand purchasing behavior, and help businesses develop effective customer retention strategies.

## Objectives

* Analyze customer purchasing behavior.
* Calculate Recency, Frequency, and Monetary metrics.
* Segment customers using K-Means clustering.
* Develop machine learning models for churn prediction.
* Visualize customer behavior and retention metrics using Power BI.
* Generate actionable business insights.

6. Dashboard development.
